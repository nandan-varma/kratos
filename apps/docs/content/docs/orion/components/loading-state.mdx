## Installation

```sh
pnpm dlx shadcn@latest add @kratos-orion/loading-state
```

## Usage

```tsx
import { LoadingState } from "@/components/ui/loading-state";

<LoadingState label="Churning" variant="drive" />
```

`variant` accepts `"drive"`, `"dots"`, or `"orbit"` — each drives the same 3×3 pixel grid with a different stagger pattern.
