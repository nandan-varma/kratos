## Installation

```sh
pnpm dlx shadcn@latest add @kratos-orion/thinking
```

## Usage

```tsx
import { ThinkingState } from "@/components/ui/thinking";

<ThinkingState variant="Steps" />
```

`variant` accepts `"Steps"`, `"Reasoning"`, `"Search"`, or `"Coding"`. The trace runs once (shimmering label → settled state), then stays expandable via the header button.
