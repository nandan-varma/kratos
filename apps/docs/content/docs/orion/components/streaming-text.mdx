## Installation

```sh
pnpm dlx shadcn@latest add @kratos-orion/streaming-text
```

## Usage

```tsx
import { StreamingText } from "@/components/ui/streaming-text";

<StreamingText />
```

Words resolve out of a blur as they stream in, an inline source chip appears mid-sentence, and once the answer settles the action row, source list, and follow-up prompts fade in.
