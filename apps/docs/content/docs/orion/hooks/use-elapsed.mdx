---
title: useElapsed
description: Ticks up in deciseconds and formats as a human-readable elapsed time string.
---

## Installation

```sh
pnpm dlx shadcn@latest add @kratos-orion/use-elapsed
```

## Usage

```tsx
import { useElapsed } from "@/hooks/use-elapsed";

const elapsed = useElapsed(); // "12.3s" or "1m 03.4s"
```

Powers the live timer in [Loading State](/docs/orion/components/loading-state).
