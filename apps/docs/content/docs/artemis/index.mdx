Artemis is a zero-dependency component registry built on [Drawably](https://www.npmjs.com/package/drawably). Every item is a real HTML control with its hand-drawn SVG chrome created after mount. The library gives each mount a unique sketch, while its CSS supplies the subtle boiling stroke effect.

## Installation

Add Artemis to `components.json`:

```json
{
  "registries": {
    "@kratos-artemis": "https://kratos.nandan.fyi/r/artemis/{name}.json"
  }
}
```

Install Drawably and its stylesheet once in your app's global CSS entry:

```sh
npm i drawably
pnpm dlx shadcn@latest add @kratos-artemis/button
```

```css
@import "drawably/style.css";
```

Do not import `drawably/font.css` unless you explicitly want Drawably Pen. Artemis uses the application's typeface by default.

## Components

Install any component independently:

- `button`, `checkbox`, `radio`, `toggle`
- `input`, `textarea`, `select`, `divider`
- `card`, `badge`, `list`
- `underline`, `highlight`, `circle`, `arrow`

Each component is a client component that re-exports the matching Drawably React primitive under the `Artemis*` name. For example, `@kratos-artemis/button` exports `ArtemisButton`.

## Theming and motion

Theme each component using Drawably's top-level props or CSS custom properties: `seed`, `roughness`, `boil`, `stroke`, `fill`, `paper`, and `width`. The underlying library already freezes boil and hover re-sketching for `prefers-reduced-motion`; Artemis adds no competing animation.
